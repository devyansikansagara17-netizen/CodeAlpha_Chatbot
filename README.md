
# CodeAlpha Assistant - Python Chatbot

## Project Overview
A customer support chatbot built using Python and Flask with a web-based chat interface.

## Features
- Instant predefined FAQ responses
- Customer service questions and answers
- Responsive HTML and CSS interface
- JavaScript frontend connected to a Flask backend
- Basic input validation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Structure
- `app.py` - Flask backend and response logic
- `templates/index.html` - Chat interface
- `static/style.css` - Website styling
- `static/script.js` - Frontend chat logic
- `requirements.txt` - Python dependencies

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

## Testing
Test messages such as "Hi", "What are your services?",
"How can I get a refund?", and "What are your support hours?"

## Project Purpose
Created as a CodeAlpha Task 4 chatbot project.
